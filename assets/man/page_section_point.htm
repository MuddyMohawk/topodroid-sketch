SKETCH SECTION POINT

This dialog is opened when you select a section-point item and tap the Edit button in the Drawing window (in "edit" mode).

Point properties:

  • size (XS, S, M, L, XL)
  • layers, the canvas views on which the point is displayed. This property is only available if the Secondary Settings > Sketching > Layers setting is set to by item [T]
  • Therion options: the sketch point has always the "-scrap" option followed by the name of the x-section
  • x-section checkbox to display the legacy xsection outline in the sketch (unplaced points only)
  • box width and box height for placed leg x-sections
  • show sketch references checkbox to toggle all the embedded viewport references for a leg x-section (station names, leg, splays, and north reference line)

Canvas views (layers)
The canvas views are presented as checkboxes with the view letter-code. You can change the views the point belongs to.

The point icon is not displayed at all if all its views are OFF. In this case the selectable point will nevertheless be shown in edit mode, so that the point edit dialog remains accessible, and a layer can be assigned to the point.

The Open button opens the dedicated x-section sketch, if it exists.
For leg x-sections the Place on plan button starts a one-shot placement on the parent plan/profile sketch. The next tap on the sketch drops a same-scale embedded x-section viewport there. If the x-section is already placed, the button becomes Re-place on plan.
The Remove from plan button removes a placed leg x-section viewport from the parent sketch but keeps the x-section file itself.
The Show sketch references checkbox toggles all the detached reference graphics in the placed viewport as one group.
Changes to the xsection sketch are propagated back to placed viewports when you return to the parent sketch.

Save confirms the changes and closes the dialog.
Cancel closes the dialog.
The BACK key closes the dialog without saving the changes.
