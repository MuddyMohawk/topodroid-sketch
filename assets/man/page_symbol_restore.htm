RESTORE DRAWING TOOLS

TopoDroid Sketch ships one canonical set of drawing tools: points, lines, and areas.

The file-backed definitions are stored in the app's private point, line, and area folders. Custom Sketch-standard definitions placed in those folders can also be loaded and edited.

Restore Drawing Tools in the Main window menu is a factory reset for drawing tools. After confirmation it permanently removes every installed symbol file, including custom files, together with enabled-tool choices, recent tools, and custom toolbar profiles. It then installs the packaged TopoDroid Sketch set and creates a fresh default toolbar.

Use the drawing-tool button on the Main window to enable or disable tools. Restoring is intended for recovering from missing, damaged, or experimental symbol files.

If a drawing refers to a symbol that is not installed, TopoDroid Sketch may substitute another symbol in the same group or use the corresponding user tool.
